# Vaiinilla Expo — cómo correr (Mac)

```bash
cd vaiinilla-expo
cp .env.example .env
npm install
npm run start
```

- Tecla `w` → navegador
- O escanea el QR con Expo Go (iPhone)
- Tecla `i` → simulador iOS (con Xcode)

En la app: Roles → Entrar como Alumno.
