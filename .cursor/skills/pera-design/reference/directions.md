# Directions, composition, vocabulary

## Pick one direction

Do not mash them together.

| Direction | Ground | Color | Default flagship signature | Refs |
|-----------|--------|-------|---------------------------|------|
| **Studio mono** | Black or white | None in chrome; all color from work imagery | Ink-fill manifesto, or horizontal scrub strip | Bakers, creatoroly, Depth Stack |
| **Warm editorial** | Putty / cream paper, warm near-black text | One hot accent | Section theme flip | Rulebase, MEK, Bao To |
| **Product narrative** | Neutral SaaS near-white | One confident accent | Hero exit + scroll spine | Bridge, Over-Stimulated |

Token values per direction: `code/tokens.css`.

## Composition

- One job per section: headline + support + one visual idea.
- Asymmetry over dashboards. Editorial imbalance beats equal widget grids on marketing surfaces.
- Whitespace is a material: museum-plinth isolation for hero components, black gutters for case-study grids, paper margins for editorial.
- Density is earned. Admin and settings UIs may be dense; marketing heroes may not.
- Desktop-first is allowed when honest — say it plainly in copy rather than shipping a broken mobile compromise.

## Brand & hierarchy

- The brand name is the loudest typographic signal in the first viewport. Remove the nav and the page must still not be anonymous.
- Hierarchy comes from scale, weight and tracking — not decorative color.
- Trust signals live inside components (credits, tags, badges, live clock), never as a separate "Trust" wallpaper section.

## Imagery

- Real artifacts: product UI, campaign stills, reels. Device frames (traffic lights + tab + URL pill) signal "this shipped".
- Grayscale skeleton illustration is fine where timelessness matters.
- One warm characterful focal per page to humanize a rigorous grid — not five.
- Backgrounds get texture, gradient, paper, photography or subtle pattern. A single sterile flat hex is not a background.

## Interaction tone

- Menus and lists: snappy, OS-native, near-instant row highlight.
- Content reveals: springy, staggered, scroll-linked.
- Destroy/delete may use physical metaphor (crumple, shred) if it finishes in ≤1.5s and never blocks the next action.
- Loading breathes. Prefer skeleton breathe over spinners when the content shape is known.

## Vocabulary

Use these words so agent and human mean the same thing.

| Term | Means |
|------|-------|
| Chrome | Nav, buttons, labels, borders, icons, panels |
| Content color | Hue supplied by media or product artifacts |
| Single accent | Exactly one intentional brand hue |
| Museum plinth | Component isolated on a soft neutral field with soft shadow |
| Device frame | Minimal OS/browser chrome around a screenshot |
| Hero budget | Brand + headline + sentence + CTA + one image |
| One composition | First viewport reads as a single staged image |
| Archive list | Text-first work index with metadata columns |
| Capability bento | Equal templated grid of skills or services |
| Display / body / meta | The three type roles |
| Kinetic type | Word-by-word staggered reveal |
| Spring appear | Content entrance with spring physics |
| Chrome fade | Fast opacity/color change for UI state |
| Merged shape | Expanding surface keeps continuous radius and connection |
| Snap highlight | Instant menu-row background, not a sliding pill |
| Blur focus | Background blur + dim while foreground engages |
| Skeleton breathe | Slow opacity pulse on placeholders |
| Ambient isolate | Decorative loop confined; chrome stays static |
| Phase offset | Parallel loops desynced on purpose |
| Numeral roll | Motion-blurred odometer value change |
| Signature detail | A one-of-one moment only this page has |
| Flagship | The page's main signature, usually scrubbed type or a theme flip |
| Scrubbed | Scroll-linked, plays both directions — vs merely triggered |
| Fingerprint layer | Always-on micro details: `::selection`, focus ring, theme-color, grain, index numerals |
| Craft bar | Minimum finish density for any element |
| Morphing pill | Selection indicator that slides/resizes via transform |
| Press scale | Brief `scale(0.96–0.98)` on `:active` |
| Full state set | Idle, hover, press, focus-visible, disabled, plus type-specific |
| Dark glass / light matte / putty | The three material grounds |
| Continuous corner | Squircle, soft continuous radius |
